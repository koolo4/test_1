# DOTA 2: ИСПЫТАНИЕ

Фанатская браузерная игра-викторина по мотивам Dota 2. Четыре режима, десять раундов в каждом, три жизни и таймер на ответ. Не связана с Valve.

## Как открыть

Сборка не нужна, зависимостей нет. Откройте `index.html` двойным щелчком — игра работает прямо из файла.

Если браузер ограничивает локальные файлы, запустите статический сервер в папке проекта:

```bash
python3 -m http.server 8080
```

и откройте <http://localhost:8080>.

## Режимы

| Режим | Что угадываем | Подсказка | Время на ответ |
|---|---|---|---|
| 🦸 Угадай героя | героя | одна из его способностей | 15 с |
| ⚔️ Угадай сборку | героя | шесть предметов его закупа | 20 с |
| 🛡️ Угадай предмет | предмет | компоненты и цена | 20 с |
| 💬 Угадай по цитате | героя | его реплика | 15 с |

## Правила

- В раунде четыре варианта ответа, верный один.
- Верный ответ: 100 очков и бонус 25 за каждый предыдущий верный ответ подряд, но не больше 100.
- Неверный ответ или истёкшее время: минус одна жизнь, серия сбрасывается.
- Партия заканчивается после десяти раундов или когда кончились три жизни.
- Рекорд по каждому режиму сохраняется в браузере и показывается на карточке режима.

## Управление

- Мышь: нажать карточку режима, затем кнопку с ответом.
- Клавиатура: `Tab` — переход между элементами, `Enter` или `Пробел` — нажатие, `Esc` — выход в меню.
- Кнопки «← В меню» и «В меню» возвращают в главное меню в любой момент.
- «Играть снова» на экране результата запускает тот же режим заново.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка трёх экранов: меню, игра, результат |
| `css/style.css` | тёмная тема, сетка, адаптив |
| `js/data.js` | данные режимов: герои, сборки, предметы, цитаты |
| `js/quiz.js` | движок: раунды, таймер, очки, жизни, рекорды |
| `js/app.js` | навигация между экранами и рекорды в меню |

## Как добавить свои вопросы

Откройте `js/data.js` и добавьте запись в `entries` нужного режима:

```js
{ clue: "Способность: <strong>Hookshot</strong>", answer: "Clockwerk" }
```

`clue` — подсказка, можно использовать теги `strong`, `em` и `br`. `answer` — правильный ответ. Уникальных ответов в режиме должно быть не меньше четырёх, иначе не набрать варианты. Количество раундов задаётся полем `rounds`.

## Технологии

Чистые HTML, CSS и JavaScript. Без фреймворков, сборки, npm и внешних запросов. Иконки — эмодзи, шрифт — системный.
